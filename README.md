# Graphic Designer Portfolio

A one-page portfolio website styled like a design tool, with rulers, a coordinate cursor, selection boxes and a layers panel.

**Sections:** Logos · Posts & posters · Packaging & digital · About · Contact

## Run locally

Open `index.html` in a browser, or start a local server:

```bash
python -m http.server 5510
```

Then go to http://localhost:5510.

## Edit content

- Projects, titles and descriptions are listed at the top of `script.js` (`LOGOS`, `POSTS`, `VISUALS`).
- The email and WhatsApp number are in the `CONTACT` block in `script.js`.
- Images are in `assets/`.

## Publish

To get a free public link, enable **GitHub Pages**: Settings → Pages → Deploy from branch → `main` / root.
